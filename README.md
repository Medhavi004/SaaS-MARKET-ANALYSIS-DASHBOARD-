# SaaS-MARKET-ANALYSIS-DASHBOARD-
Amazon Ecommerce Analysis and Interactive Dashboard Created Using Excel and Power BI

## 📊 Project Overview

This project analyzes a SaaS market dataset containing 264 software products across different categories and business segments.

The analysis focuses on:

- SaaS pricing
- Free-plan availability
- Product ratings
- Feature coverage
- Market segments
- Value-for-money
- Category-level comparison

The project combines **Excel analysis and Power BI visualization** to convert raw SaaS data into meaningful business insights.

---

## 🎯 Business Objective

The main objective of this project is to understand the SaaS market and answer important business questions such as:

- How many SaaS products offer a free plan?
- Which categories have the highest pricing?
- Which products have the highest ratings?
- Which categories have the best average ratings?
- Does a higher number of features relate to higher ratings?
- Which market business segment has the most products?
- Which categories provide the best value?
- Which products offer many features at a relatively low price?

---

## 🗂️ Dataset

The dataset contains information about SaaS products including:

| Column                | Description                                |

| Tool Name             | Name of the SaaS product                   |
| Category              | Product category                           |
| Business Segment      | Business/market segment                    |
| Free_Plan             | Indicates whether a free plan is available |
| Starting_Price_Usd    | Starting price of the product              |
| Highest_Plan_Price_Usd| Highest available plan price               |
| Plan_Count            | Number of pricing plans                    |
| Rating                | Product rating                             |
| Features_Count        | Number of product features                 |
| Website               | Product website                            |
| Price_Category        | Pricing classification                     |
| Rating Level          | Rating classification                      |
| Free Plan Label       | Free-plan classification                   |
| Value Score           | Calculated value-for-money metric          |
